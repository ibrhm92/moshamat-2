# مساهمات - نظام إدارة المدفوعات الجماعية

## 🚀 كيفية إنهاء الوضع التجريبي وتفعيل النظام

### 1. إنشاء مشروع Firebase
1. اذهب إلى [Firebase Console](https://console.firebase.google.com/)
2. سجل الدخول بحساب Google
3. اضغط على "إضافة مشروع"
4. أدخل اسم المشروع (مثال: "moshamat-app")
5. اختر تفعيل Google Analytics (اختياري)
6. اضغط "إنشاء مشروع"

### 2. إعداد Firestore Database
1. في مشروعك، اذهب إلى "Firestore Database"
2. اضغط "إنشاء قاعدة بيانات"
3. اختر "ابدأ في وضع الإنتاج"
4. اختر موقع قاعدة البيانات (الأقرب لمستخدميك)
5. اضغط "تفعيل"

### 3. الحصول على إعدادات Firebase
1. في إعدادات المشروع، اذهب إلى "General"
2. اسحب لأسفل إلى "Your apps" section
3. إذا لم يكن هناك تطبيق ويب، اضغط "</> Web"
4. أدخل اسم التطبيق (مثال: "moshamat-web")
5. اضغط "تسجيل التطبيق"
6. انسخ إعدادات Firebase

### 4. تحديث ملف الإعدادات
1. افتح ملف `scripts/firebase-config.js`
2. استبدل القيم النائبة بإعدادات Firebase الحقيقية:
```javascript
const FIREBASE_CONFIG = {
  apiKey: "AIzaSyBhK8m9X7Z2wQ1rT3yV6uN8pL5oI2sE4fG",
  authDomain: "moshamat-app.firebaseapp.com",
  projectId: "moshamat-app",
  storageBucket: "moshamat-app.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abcdef123456789012345678"
};
```

### 5. إعداد قواعد الأمان (اختياري)
1. في Firebase Console، اذهب إلى "Firestore Database"
2. اضغط على "Rules" tab
3. يمكنك استخدام القواعد الموجودة في ملف `firestore.rules`

### 6. تشغيل التطبيق
1. افتح الملف الرئيسي `index.html` في المتصفح
2. أو استخدم خادم محلي:
```bash
python -m http.server 8000
```
3. افتح `http://localhost:8000`

## ✅ التحقق من النجاح

بعد تحديث إعدادات Firebase، ستجد:
- شريط أخضر في الأعلى يعرض "وضع الإنتاج (Firebase)" في صفحة الإعدادات
- البيانات تحفظ تلقائياً على Firebase
- لا تظهر رسالة "وضع التجريب"

## المسؤولون والمجموعات

- لكل مساهم حقل اختياري `referredById` يشير إلى معرّف مساهم آخر. غياب الحقل في السجلات القديمة يعني «بدون مسؤول»؛ لا يلزم ترحيل أو تعديل المدفوعات.
- اختيار المسؤول متاح عند إضافة مساهم من صفحة المساهمين أو أثناء تسجيل أول مساهمة، وعند تعديل بياناته. يمكن تحديد عدة مساهمين وتعيين مسؤول لهم مرة واحدة (٤٠٠ كحد أقصى).
- الربط الفردي والجماعي يُحفظ بمعاملة Firestore تتحقق من وجود المسؤول ومنع الربط الذاتي والدائري قبل كتابة أي تغيير. إزالة الربط تكتب `null` فقط. لا يُسمح بتعيين مسؤول مؤرشف جديد، ولا بحذف مسؤول له تابعون قبل نقلهم أو إزالة ربطهم.
- صفحة «المسؤولون والمجموعات» تعرض إحصائيات شهرية وتفاصيل المجموعة المباشرة النشطة فقط. مساهمة المسؤول نفسه منفصلة؛ التابعون غير المباشرين والمؤرشفون خارج متابعة المجموعة. المدفوعات الأصلية للمؤرشفين تبقى في التقارير الموجودة.
- الإحصائيات حسب **الربط الحالي**، حتى عند اختيار شهر قديم؛ لا يمثل ذلك تاريخ تغيّر المسؤولية. وجود سجل دفع للشهر يعني «دفع» مهما كانت قيمته، والمبالغ المتعددة للشخص تُجمع دون تكراره في عدد الدافعين.
- رسالة المسؤول تُعرض للمراجعة، مع خيار المتأخرين فقط وإظهار/إخفاء المبالغ. فتح واتساب يوجّه الرسالة لرقم المسؤول المسجل ولا يرسل تلقائيًا؛ تتوفر إمكانية نسخ الرسالة عند غياب الرقم.

اختبارات الحسابات والتحقق والحفظ الذري:

```sh
node --test tests/*.test.js
```

### البحث والتصفية عند إضافة مساهمة

اختر الشهر ثم المسؤول (الكل، بدون مسؤول، أو مسؤول محدد). تظهر الأسماء النشطة التي لم تسجل دفعًا في الشهر فقط، ويظهر عدد المتاحين. الفلتر يختار المجموعة المباشرة ولا يغيّر ربط المساهمين.

البحث يقبل أجزاء الاسم غير المتجاورة وبأي ترتيب، مع تسوية اختلافات العربية والتشكيل، أو جزءًا من الهاتف بالأرقام العربية أو الإنجليزية. تعرض النتيجة الهاتف والمسؤول لتمييز الأسماء المتشابهة. زر إضافة مساهم جديد مستقل ومتاح حتى عند عدم وجود نتائج. تغيير الشهر أو المسؤول يمسح اختيار المساهم والهاتف لمنع تسجيل مساهمة لشخص من مجموعة سابقة.

### تحديد المساهمين ورقم المسؤول

في صفحة المساهمين، البحث داخل منطقة التعيين الجماعي يدعم أجزاء الاسم بأي ترتيب واختلافات العربية. التحديد يظل محفوظًا عند تغيير البحث، والعداد يوضح المحددين خارج النتائج. «تحديد كل الظاهرين» يحدد النتائج الظاهرة فقط، ويمكن مسح البحث أو إلغاء تحديد الجميع.

عند إضافة مساهم جديد من شاشة إضافة مساهمة، يمكن تفعيل «استخدام رقم هاتف المسؤول لهذا المساهم». يُنسخ رقم المسؤول المختار ويُحفظ للمساهم الجديد؛ لا تتغير بيانات المسؤول أو الأرقام القديمة ولا يوجد ربط تلقائي لتحديث الأرقام مستقبلًا. تغيير المسؤول يحدّث الرقم قبل الحفظ، وإلغاء الخيار يعيد الرقم اليدوي السابق. يلزم مسؤول له رقم موبايل مصري صحيح عند تفعيل الخيار.
